# 1:1 AI Interview Prep Tool

> An AI-powered personal interview practice platform with adaptive conversations
> and voice interaction.

The project explores how Large Language Models and conversational AI can be
used to simulate realistic one-to-one interview experiences.

## 🚀 Current Focus

- AI-powered interviewing
- Adaptive follow-up questions
- Conversational context
- Interview session management
- Voice interaction
- Role-specific interview practice

## 🛠️ Tech Stack

- Python
- Flask
- LLMs
- Groq
- Llama
- ElevenLabs
- HTML/CSS/JavaScript

## 📌 Project Status

🚧 **Active Development**

The current repository contains an experimental working implementation.
Additional intelligence, persistence, evaluation, and production features
will be developed progressively.
